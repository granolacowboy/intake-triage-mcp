# Evaluation evidence

This directory is reserved for **reviewed, reproducible evaluation evidence**.

A model-driven report belongs here only when it records the exact server commit/tag/digest, exact harness revision, suite SHA-256, exact model identifier, UTC timestamp, and answer/trace assertions.

A manually typed "10/10" badge is intentionally not evidence. Results can change when the server, suite, harness, model, or provider changes.

The repository ships the suite and machinery to generate evidence. A paid/model-driven result is not fabricated or committed automatically.
